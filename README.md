# Advik Jewellers - Premium E-Commerce Website

A premium frontend web project designed for a 1-gram gold jewelry storefront. This responsive website showcases high-quality jewelry collections with an elegant, modern dark-gold aesthetic.

## 🚀 Live Link
View the project live here: https://github.io

## ✨ Features
- **Premium Design Theme:** Styled with professional dark-gold and charcoal color schemes.
- **Product Display Grid:** Clean layout showcasing various collections like Mangal Sutras, Necklaces, and Designer Rings.
- **Direct Contact Integrations:** Fully functional quick links connecting customers straight to WhatsApp and Call features.

## Technologies Used
- HTML5 for web structure
- Custom CSS3 for modern layouts and brand styling
- Git & GitHub for professional version control
